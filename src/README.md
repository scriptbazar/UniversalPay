<h1 align="center">UniversalPay</h1>

<p align="center">
  A secure, scalable, and globally functional payment gateway platform built with Next.js, Firebase, and Genkit.
</p>

---

## 🚀 Quick Setup

### 1. Link your Repository
```bash
git remote set-url origin <YOUR_ACTUAL_REPO_URL>
```

### 2. Install
```bash
npm install
```

### 3. Environment Variables
Ensure your `.env` file contains:
- `NEXT_PUBLIC_FIREBASE_API_KEY`
- `GEMINI_API_KEY`
- Other Firebase config values.

---

## 🛠️ Troubleshooting

If you encounter **"Git: remote: Repository not found"**, it means your Git `origin` is pointing to a placeholder URL. Update it using:
`git remote set-url origin https://github.com/YOUR_USERNAME/YOUR_REPO.git`
